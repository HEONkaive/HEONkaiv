HEON ARCHIVE v1.1.8 (v1.1.7 기반 UI 업데이트)

1. 상단 검색창 왼쪽에 과목 선택 필터를 배치했습니다. 기본값은 현재 선택한 과목이며 전체 과목도 검색 가능합니다. 검색 결과마다 과목명·교수명을 표시합니다.
2. 검색창에 표시되던 / 단축키 배지를 제거했습니다. / 키 검색 이동 단축키 자체는 유지됩니다.
3. 미확정 건수 버튼에 마우스 호버/키보드 포커스 상태를 추가했습니다.
4. 오답노트·북마크·Review의 번호 상자는 문항 번호만 표시하며 정답 초록, 오답 빨강, 채점 보류 노랑, 미풀이 중립색으로 구분합니다.
5. 해당 Review 화면의 상단 학습 요약·진행률·기록 초기화·PDF 버튼 배치를 정리했습니다. 기록 초기화 기능의 동작은 변경하지 않았습니다.
6. 문항·정답·Supabase·학습 기록 저장 키는 수정하지 않았습니다.
7. UI 변경 사항이 새로 고침 시 즉시 반영되도록 스타일/스크립트 및 PWA 캐시 버전을 갱신했습니다.

패치 적용: v1.1.7 기준, 패치 ZIP의 HEONkaive/ 경로를 기존 사이트의 동일 경로에 덮어쓰세요.
