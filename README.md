# HEON ARCHIVE v12.5 — 22학번 통합 및 학습모드 개편

본 버전은 v12.4의 전체 프로젝트를 보존하고 다음 기능을 추가한 **GitHub Pages용 정적 웹사이트**입니다.

## 새 기능

- 과목 선택 화면의 **교수님별 / 단원별 / 학번별** 세 가지 학습모드
- 각 모드의 제출 답안, 진행률, 북마크와 마지막 위치를 **서로 독립 저장** (이전 `heon.archive.learning.v1` localStorage 키 유지)
- 교수님별 선택 화면에서 한 줄에 3개 카드; 학번별 한 줄 3개 카드; 단원은 교수님을 누른 뒤 강의안 제목 기준 선택
- **이강규 교수님 AI 예상문제 25제**는 교수님 카드 바로 아래; 별도 진행률 및 저장기록
- 시험 결과: 왼쪽 번호 **1, 2, 3 …**, 오른쪽 선택된 문제 원본, 정답·오답·미제출·채점보류, 해설, 강의안 캡처. 세로 스크롤 독립
- 학번별 시험에는 새 교수님 문항이 모두 포함되도록 교수님 데이터 동적 집계; 동일 학번·번호라도 다른 문제인 경우 유실 방지

- 공식 객관식 정답은 **마지막 PDF 7쪽의 정답표만 사용**. 표는 왼쪽 1~5, 오른쪽 6~10, 이후 다음 묶음 순서. **8번이 ①·②·④ 복수정답** (38번은 ④)

## GitHub Pages 배포

1. ZIP을 풀고 `HEON_ARCHIVE_v12_5` 폴더 **안의 내용** (`index.html`, `app.js`, `styles.css`, `data`, `assets` 등 전체)을 GitHub 저장소의 **루트**에 복사합니다.
2. GitHub Desktop의 Changes에서 신규 22학번 PDF/이미지 및 기존 파일 수정이 포함되는지 확인 후 Commit → Push origin을 누릅니다.
3. Settings → Pages에서 해당 브랜치의 루트(`/`) 게시가 활성화됐는지 확인합니다.
4. 브라우저에서 Ctrl+Shift+R 강력 새로고침합니다. 캐시 버전 `12.5.0` 적용.
5. 화면에서 22학번 통합 시험 71개, 8번 복수 답안 체크, 시험 결과 번호, 단원별 독립 기록을 확인하세요.

**저장 방식:** 브라우저 localStorage; 파일을 GitHub에 재업로드해도 같은 사이트 주소·브라우저에서 기록을 보존하도록 설계되었습니다. 그러나 사이트 주소를 변경하거나 브라우저 기록을 지우면 기록이 사라질 수 있습니다. 민감한 개인 정보는 업로드하지 마세요.

**저작권·배포:** 시험지 및 강의안 원본 이미지를 공개 GitHub 저장소에 게시할 권한을 확인하세요.

## 데이터 수정 방법

- 각 교수님 원본 데이터는 `data/professors/<slug>.json`; 사이트 오프라인 로딩용 `.js` 미러도 함께 수정해야 현재 배포 구조에 반영됩니다.
- `data/catalog.json`과 `data/catalog.js`에는 교수님 메타와 문제 수가 있습니다.
- 새 문제는 기존 ID를 재사용하거나 변경하지 마세요. 예전 기록 충돌을 막기 위한 안정성 규칙입니다.
- `answerSource`, `validation.stage`, `evidence`, `candidateEvidence`, `aiExplanation`, `unitId`, `unitTitle`의 출처를 서로 구별하세요.
