## v9 새 기능

1. 홈 화면은 **왼쪽 과목 선택 / 오른쪽 교수님별 풀기 또는 학번별 시험** 구조입니다. 상단 4개 과목 메뉴는 유지합니다. 혈액과 종양 1차를 선택하면 교수님 5명 또는 등록된 17~21학번을 고를 수 있습니다.
2. **교수님별 풀기**는 이전 방식 그대로 교수님 단위 전체/연도 필터, 검색, 북마크, 오답 복습, Review, 학습기록 초기화 기능을 제공합니다.
3. **학번별 시험**은 같은 과목에 등록된 모든 교수님의 특정 학번 문제를 모아 출제합니다. 서로 다른 교수님에 같은 학번·문제 번호가 있으면 한 문항으로 중복 제거합니다. 이미 제출한 답안은 자동 복원됩니다.
4. 학번별 시험에서 **마지막 미제출 문제까지 모두 제출하면 결과 화면으로 이동**합니다. 총 문항 수, 정답, 오답, 보류, 미제출을 표시하고 문제를 누르면 해당 지문·원본·강의안 해설로 이동합니다. 미확정 정답은 오답 통계에 포함하지 않습니다. 시험 데이터는 교수님별 모드와 동일한 문제 ID를 사용하므로 동일한 제출 기록이 교수님별 진행률에도 반영됩니다.
5. **이승신 교수님 36문항 추가**, 실제 원본 CT/영상이 필요한 문항은 문제 본문에 표시. 근거 채택 21문항 / 검토 필요 15문항. 단, 검증 채택 중 *서술형* 2문항은 강의안 모범답안이 있어도 자동 채점하지 않고 **채점 보류**로 표시합니다. [검증 보고서](AUDIT_이승신_v9.md)를 참고하세요.
6. **김혜원 교수님 20-6과 21-2 정답을 ③번으로 사용자 확정**했습니다. 기존 답안·북마크는 유지합니다. [정답 변경 기록](AUDIT_김혜원_v9_사용자정답.md)을 참고하세요.
7. 기존 다크모드/라이트모드, 반응형 레이아웃, 해설 접기·열기(해설 독립 스크롤), 기출 이미지 기본 접기, PC 하단 고정 이전·다음·제출 버튼, 문제 ID 및 저장 기록 방식 유지.

## 배포 (GitHub Desktop 권장)

1. 배포용 ZIP을 압축 해제합니다.
2. `heon-archive` 폴더 **안**의 `index.html`, `app.js`, `styles.css`, `data/`, `assets/`, `tools/`와 기타 파일을 GitHub 저장소 최상위(루트)에 복사합니다. `heon-archive` 폴더 자체를 루트에 중첩으로 올리지 마세요.
3. GitHub Desktop에서 **Commit to main → Push origin**을 실행합니다.
4. GitHub 저장소 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 설정합니다. 이전에 배포 중이면 기존 설정을 유지합니다.
5. 사이트에서 예전 화면이 보이면 `Ctrl + Shift + R`로 캐시 새로고침을 하세요.

**경고:** 공개 GitHub Pages 사이트에 PDF 원본 캡처를 포함하면 외부 사용자가 열람할 수 있습니다. 기출문제·강의안 원본과 이미지의 게시/재배포 허가를 먼저 확인하세요.

## 자동 저장·기록 보존

- `localStorage` 키 `heon.archive.learning.v1`에 **선택한 답안/제출/북마크/사용자 확정 정답/교수님별 진행률**을 저장합니다. 문제 고유 `id`는 기존 버전과 같습니다.
- 브라우저·기기 간 동기화는 없으며, 브라우저 데이터를 삭제하거나 도메인을 바꾸면 이전 기록이 안 보일 수 있습니다.
- 최초 v9 접속 시 김혜원 20-6·21-2에 대한 오래된 **브라우저 개인 정답 지정값만** 한 번 정리해 새 ③번 기준을 사용합니다. 두 문제의 이전 제출 답안·북마크·다른 교수님의 학습기록은 유지합니다.
- 학번별 시험에서 제출한 기록은 교수님별 학습 기록과 공유됩니다. 처음부터 새로운 시험 기록으로 재응시하려면 해당 교수님들의 기록을 개별 초기화해야 하며, 초기화 시 확인을 요구합니다.

## 문제 텍스트 직접 수정 / 새 교수님 추가

```text
heon-archive/
├─ index.html
├─ app.js
├─ styles.css
├─ data/
│  ├─ catalog.json, catalog.js
│  └─ professors/
│     ├─ park-murim.json, park-murim.js
│     ├─ lee-seoul.json, lee-seoul.js
│     ├─ kim-hyewon.json, kim-hyewon.js
│     ├─ choi-duyoung.json, choi-duyoung.js
│     └─ lee-seungshin.json, lee-seungshin.js
├─ assets/
│  ├─ questions/  # 문제 원본 PDF 캡처
│  ├─ figures/    # 문제에 바로 노출될 필수 CT·영상·그래프 등
│  └─ evidence/   # 강의안 원본 페이지 캡처 (확정 또는 미채택)
├─ tools/
│  └─ sync_offline_data.py
├─ AUDIT_이승신_v9.md
├─ AUDIT_김혜원_v9_사용자정답.md
└─ README.md
```

- 원본 문제 문장을 수정하려면 `data/professors/교수님ID.json`에서 `prompt` 또는 `choices[].text`만 수정합니다. **`id`는 변경하지 마세요.**
- JSON 파일을 수정한 후 프로젝트 루트에서 `python tools/sync_offline_data.py`를 실행합니다. 브라우저에서 직접 파일을 열 때 필요한 `.js` 사본도 함께 갱신됩니다. GitHub에는 **JSON과 JS 양쪽을 업로드**해야 수정이 반영됩니다.
- 새 교수님: 새 JSON + 이미지 폴더를 만들고 `data/catalog.json`에 교수님을 추가한 뒤 동일한 동기화 스크립트를 실행합니다.
- 정답 출처는 강의안 이중검증 `lecture_double_checked`, 사용자가 지정한 정답 `user_confirmed`, 미확정 상태 `pending`으로 분리해 저장합니다. 강의안이 직접 뒷받침하지 않는 보기에 임의 정답을 부여하지 마세요.
- 일부 기출은 필기, 스캔 손상 및 2단 텍스트가 섞여 있어 **원문을 읽기 쉽게 정리한 문장**입니다. 문제의 실제 표현이 중요한 경우 각 문제의 원본 캡처와 대조하세요.

## 테스트와 제한사항

- 교수님·학번별 목록, 17학번 통합 시험 전체 문항 수와 최종 결과 자동 표시, 문제별 Review 복귀, 이승신 교수님 이미지/근거 표시, 김혜원 정답 정정, 모바일/PC 표시, 이전 localStorage 기록을 검사했습니다.
- `file://`·`localhost` 탐색이 제한된 테스트 브라우저에서는 사이트 JS와 데이터를 **테스트 페이지에 직접 로드하는 방식**으로 검증했습니다. **실제 사용자의 GitHub Pages에 올려 실행까지 확인한 것은 아닙니다.**
- 채택 21문항 중 두 개의 서술형 문항은 모범답안은 있으나 자동 정오답 점수 계산 대상이 아닙니다. 원본에 글자 판독이 불확실한 내용은 사용자 확인이 필요합니다.


## v10: 이강규·정유리 교수님 추가 및 학번별 기록 분리

- 혈액과 종양 1차에 이강규 21문항, 정유리 21문항 추가. 기존 215문항과 합해 **실제 기출 257문항**.
- **이강규 AI 예상문제 25개**는 교수님별 선택 화면 맨 아래의 별도 버튼에서 접근. 실제 기출은 아니며 학번별 통합시험에서 제외됨.
- 기존 교수님별 제출 기록은 그대로 유지하며 **학번별 시험 기록은 새로 분리하여 저장**합니다. 따라서 교수님별로 전부 풀었어도 학번별 시험은 0%로 시작합니다. 두 모드의 북마크도 서로 독립적입니다.
- 동일한 학번·문항 번호를 두 교수님 데이터에서 발견했을 경우, 번호만 같고 문제가 다르면 **둘 다 출제**합니다. 지문 앞부분까지 같은 중복 문항만 1개로 합칩니다.
- 21학번 일부 문제의 분류는 2023학년도 시험지를 바탕으로 한 **추정**이며, 감사 보고서를 참조하세요.
- v10의 신규 기출 42문항 중 16문항은 강의안 근거 채택, 26문항은 검토 필요입니다. **전부 원문 축어 전사 완료라고 표시하지 않으며** 미확정 원문은 캡처에서 확인해야 합니다.
- 최두영 교수님 20-14는 **사용자 확정 정답 ②**를 반영했습니다.
