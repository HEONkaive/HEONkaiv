# HEON ARCHIVE v10.1 — 박무림·이승신 교수님 범위 재분류

GitHub Pages에서 실행하는 정적 HTML/CSS/JavaScript 의학 기출문제 아카이브입니다. **v10 디자인과 모든 학습 기능은 유지**하고, 비응급 문항의 소속 및 근거 PPT(PDF 강의안 원본 캡처)를 박무림 교수님으로 이동했습니다.

## 이번 변경 결과

|---|---:|---:|
| 박무림 | 107 | 4 |

- v10에서 이승신 교수님 36문항 중 19문항을 박무림 교수님으로 재분류했습니다.
- 옮긴 19문항 중 5문항(`17-18`, `17-19`, `17-21`, `20-3`, `20-4`)은 이미 박무림 교수님에게 **같은 기출**이 있어서 중복을 병합했습니다. 기존 박무림 교수님 정답(특히 사용자 확정)은 유지했습니다.
- 나머지 **14문항은 박무림 교수님 신규 등록**입니다. 이승신 교수님에게는 **종양학적 응급질환 17문항만 남았습니다.**
- 따라서 총 기출의 중복 제거 수는 `257 → 252`입니다. 이강규 교수님 **AI 예상문제 25문항은 별도**로 유지하며 연도별 기출에 포함되지 않습니다.

## 강의안 이중 검정 및 해설

기출 원본과 다음 **박무림 교수님 강의안 원본**을 다시 대조했습니다. 강의안 캡처는 `assets/evidence/park-murim/` 아래 있습니다.

- **원발병소불명암**: PDF 2, 3, 4, 5, 7쪽
- **암역학 및 예방·암선별검사·종양표지자**: PDF 25, 29, 30, 32쪽
- **항암치료총론**: PDF 7쪽(ECOG PS), 29쪽(Loeb 제4원칙)

관련 강의안으로 정답을 직접 검정하지 못한 문항은 **정답 검토 필요** 상태로 남겨 뒀습니다. 예를 들어 `17-주3` CML 역학, `21-주1` Triple endoscopy는 강의안에서 일치하는 원문을 확보하지 못했습니다. 서술형 4문항은 모범답안을 확인했더라도 자동 정오답 채점하지 않도록 했습니다.

모든 문항별 이전/이후 ID, 강의안 파일명, PDF 쪽수 및 채택·미채택 상태는 [검증 기록](AUDIT_v10_1_이승신_박무림_범위이전.md)에 있습니다.

## 학습 기록 호환

기존 저장 키 **`heon.archive.learning.v1`**을 유지합니다. v10.1 최초 실행 시 브라우저에 남아 있는 옛 `lee-seungshin:*` 기록 중 재분류된 19문항은 새 `park-murim:*` ID로 **복사**합니다.

- 교수님별 답안(`records`) 및 학번별 시험 답안(`yearExamRecords`)은 **각각 독립적으로 이관**합니다.
- 북마크·개인 지정 정답·최근 문제 위치도 가능한 범위에서 이전합니다.
- 동일한 문항이 기존 박무림 교수님 쪽에도 있으면 박무림 학습 기록과 확정 정답을 우선합니다.
- **옛 기록 키를 지우지 않으므로** 이관 과정에서 원본 기록을 삭제하지 않습니다.
- 브라우저에 저장된 기록은 해당 사이트 주소/기기에만 있으며, GitHub 자체에 기록이 업로드되지 않습니다.

## GitHub Pages 업데이트

1. 전체 ZIP을 압축 해제합니다.
2. `HEON_ARCHIVE_v10_1` 폴더 **안의** `index.html`, `app.js`, `styles.css`, `data/`, `assets/` 등 파일과 폴더 전체를 기존 GitHub 저장소의 **루트**에 복사합니다. 기존 파일은 덮어씁니다.
3. GitHub Desktop을 이용해 **Commit → Push origin**을 진행합니다.
4. 기존 GitHub Pages 주소에서 `Ctrl+Shift+R`로 강력 새로고침합니다. v10.1은 CSS/JS/문제 데이터 버전 `10.1.0`으로 캐시를 갱신했습니다.
5. 사이트에 접속해 **박무림 107문항 / 이승신 17문항**으로 나타나는지 확인합니다.

기출·강의안 이미지를 공개 GitHub 저장소에 올리기 전에 해당 자료의 배포 권한을 확인하세요.
