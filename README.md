- 기출 정리본에 함께 수록된 `19-54`/`20-65`는 이서울PF TBL 내용이라는 주석이 있고 현재 이서울 교수님으로 **이미 등록**되어 있어 중복 생성하지 않았습니다.

**① 강의안 실제 페이지와 해당 내용 대조 → ② 원문 문제와 선택지 전부 비교 → 일치할 때만 근거 채택.** 기출 정리본의 형광펜 표시 자체는 근거가 아닙니다. 20-6 / 21-2는 강의안에서 ‘악성 **의심**’을 설명하지만 문제의 ‘유방암을 **나타낸다**’는 더 단정적인 표현이어서 정답 확정 대신 **검토 필요**로 남겼습니다. 이 문제들은 참고용 강의안 캡처를 채택 근거와 구분해 표시합니다. 원본 PDF 페이지는 1부터 세며 PDF 내부 인쇄 슬라이드 번호와 다를 수 있습니다.

## GitHub Pages에 배포하거나 업데이트하기

1. ZIP 압축을 푼 뒤, **`heon-archive` 폴더 안에 있는 모든 파일과 하위 폴더**를 GitHub 저장소 최상위에 업로드합니다. `index.html`이 저장소 최상위에 있어야 합니다.
2. 기존 HEON ARCHIVE 사이트라면 같은 저장소의 파일을 **동일 경로에서 덮어쓰고** 김혜원 신규 파일/이미지를 추가합니다. 많은 이미지는 GitHub Desktop에서 Commit → Push origin 하는 것이 편리합니다.
3. 새 저장소라면 `Settings → Pages → Deploy from a branch → main / (root)`를 선택합니다. 이미 설정했다면 바꾸지 않습니다.
4. 배포 후 이전 화면이 보이면 `Ctrl+Shift+R`로 강력 새로고침합니다.

학습 기록은 **`heon.archive.learning.v1`** 이름으로 브라우저 `localStorage`에 저장됩니다. 문제 선택은 즉시 저장되고 답안 제출 시 완료 처리됩니다. **기존 GitHub Pages 주소와 브라우저를 유지해야 기존 기록이 보존됩니다.** 다른 기기 사이에는 자동 동기화되지 않습니다. 브라우저 데이터가 삭제되면 기록이 사라질 수 있습니다.

> **주의:** 이번 박무림 정답 수정 10개는 강의안 이중검증 결과가 아니라 **사용자 확정** 정답입니다. 이전 브라우저에서 이 10문항에 저장해 둔 별도 사용자 지정 정답만 최초 로드 시 해제하고, 제출했던 선택 답안·북마크·다른 교수님 기록은 그대로 유지해 새 정답 기준으로 채점합니다.

## 실행 방법

ZIP을 압축 해제한 후 `index.html`을 열거나, 폴더에서 `python -m http.server 8000`을 실행해 `http://localhost:8000/`에 접속합니다. 정적 HTML/CSS/JavaScript이므로 서버 없이 GitHub Pages에서도 작동합니다. `file://` 환경은 브라우저 정책 차이가 있을 수 있으므로 배포 환경에서 확인하는 것을 권장합니다.

### 문제 텍스트 직접 수정하는 방법

**`.json`을 원본으로 수정**하세요. 예: 김혜원 교수님은 `data/professors/kim-hyewon.json`. 문제 지문은 `prompt`, ①~⑤ 내용은 `choices[i].text`, 정답은 `answer`입니다. 문제 `id`는 기존 학습 기록과 연결되므로 변경하지 마세요.

수정 후 **`python tools/sync_offline_data.py`**를 실행하면 브라우저용 `.js` 사본이 자동 갱신됩니다. GitHub에는 수정한 `.json`과 `.js`를 함께 올리세요. `.js` 파일만 수정하면 재생성할 때 변경이 사라집니다.

### 교수님 새로 추가하기

`data/professors/<id>.json`과 이미지 폴더를 만들고, `data/catalog.json`의 해당 과목에 교수님 항목을 추가한 뒤 `sync_offline_data.py`를 실행하세요. HTML 전체를 수정할 필요가 없습니다. 안정적인 문제 ID 형식은 `교수님-id:학번-문항번호`입니다.

### 테스트와 유의 사항

`python tools/check_v7_data.py`로 문제 ID·정답·이미지 파일 경로·연결 상태를 검사합니다. PC·모바일에서 교수님 선택, 문항 이동, 원본 그림 노출, 제출 후 해설 및 기존 정답 수정 표시도 테스트했습니다. **실제 GitHub Pages 게시까지 수행한 것은 아닙니다.** 강의안/기출 PDF 캡처를 공개 저장소에 올릴 때에는 재배포 권한을 확인하세요.
