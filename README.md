## GitHub Pages에 업로드하기

**기존 HEON ARCHIVE 사이트 URL과 저장소를 유지하는 것이 학습기록 보존에 중요합니다.**

1. ZIP을 완전히 압축 해제합니다.
2. 압축 해제된 `heon-archive` 폴더 **안쪽**의 `index.html`, `app.js`, `styles.css`, `data/`, `assets/`, `tools/`, `README.md`, 두 AUDIT 문서를 GitHub 저장소 **최상위**에 복사합니다. 기존 파일은 **같은 경로에서 덮어쓰고**, 새 폴더들은 추가합니다.
3. GitHub Desktop에서 **Commit to main → Push origin**을 실행하세요. GitHub 웹 업로드는 파일이 많은 폴더를 한꺼번에 처리하기 불편할 수 있습니다.
4. 저장소의 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/(root)`을 선택합니다(이미 배포 중이면 기존 설정을 유지합니다).
5. 배포된 동일한 주소에서 새로고침(`Ctrl + Shift + R`)합니다.

기존 박무림 교수님 `id`와 데이터 저장 키 **`heon.archive.learning.v1`를 변경하지 않았습니다**. 같은 사이트 URL/브라우저에서 이전 풀이 기록을 읽도록 설계했습니다. 서로 다른 사이트 URL, 브라우저 또는 기기 사이에는 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하면 학습 기록도 사라질 수 있습니다.

> **저작권·공개 범위:** 공개 GitHub Pages에 강의안과 기출문제 캡처를 올리면 누구나 이미지에 접근할 수 있습니다. 배포 전 강의자료 재사용·게시 권한을 확인하세요.

### 새 교수님 추가 방법

1. `data/professors/<교수님-id>.json`을 기존 이서울·박무림 파일과 같은 구조로 만듭니다.
2. 원본 문제 이미지는 `assets/questions/<교수님-id>/`, 근거 원본 이미지 파일은 `assets/evidence/<교수님-id>/`에 추가합니다.
3. `data/catalog.json`에서 해당 과목의 `professors` 배열에 새 교수님 ID·표시 이름·JSON 파일 경로를 추가합니다.
4. `python tools/sync_offline_data.py` 실행 후 생성된 `.js` 파일까지 GitHub에 업로드합니다. **기존 HTML의 코드 전체를 수정할 필요는 없습니다.**

`문제 id`는 `lee-seoul:21-63`과 같이 교수님 ID가 포함된 **영구 식별자**입니다. 이미 공개된 문제의 id를 다른 문제에 재사용하지 마세요. 새로운 문제를 추가해도 기존 답안/북마크/진행률은 해당 ID로 유지됩니다.

### 학습기록 정책

선택지 클릭 즉시 답안을 저장하고, **답안 제출을 눌러야만 완료 문제 수가 증가**합니다. 정답이 불확실한 문항은 제출 후 `채점 보류`로 집계하며, 사용자가 직접 정답을 지정하면 브라우저 저장·Review·정오답 통계에 반영합니다. 교수님별 초기화는 해당 교수님의 선택 답안·제출 기록·북마크·직접 지정한 정답만 지우고 다른 교수님의 기록은 유지합니다.

**이 프로젝트는 강의안 중심의 시험 복습 도구이며, 실제 임상 진료 판단에 사용하지 마세요.**

## v6 UI 사용법

- **사이트 첫 진입은 항상 교수님 선택 화면**입니다. 같은 교수님을 다시 선택하면 마지막 문제부터 이어집니다.

- PC는 왼쪽 문제 / 오른쪽 해설 공간의 비율을 고정하여, 해설창을 열고 닫더라도 **문제의 폭이 바뀌지 않습니다.** 원본은 여전히 접힌 상태로 출발합니다.
- 데스크톱에서는 **이전 / 다음 / 제출**이 양쪽 스크롤 패널 아래의 고정 작업 표시줄에 있습니다. 모바일에서는 기존 문항 내부 버튼을 사용합니다.
- **박무림 교수님 18-39**의 ②번에서 필기만 제거하고, 정답은 사용자가 확정한 ⑤번으로 저장했습니다. 해당 정답은 강의안에서 확인된 정답과 구분합니다.
- 기존 파일을 교체할 때 동일한 GitHub Pages 경로 및 저장 키 `heon.archive.learning.v1`를 사용하면 기존 응답 기록을 그대로 읽습니다. 기존 18-39의 풀이 기록이 있다면 ⑤번 정답 기준으로 재채점됩니다.

기존 버전에서 18-39의 **개인 지정 정답**이 있었다면 최초 업데이트 시 그 지정만 한 번 해제하여 ⑤번을 새 기준으로 사용합니다. 이미 제출했던 선택 답안·북마크·진행률은 그대로 보존합니다. 이후 원하는 경우 해설창에서 직접 다시 지정할 수 있습니다.
