HEON ARCHIVE v1.0.7 - 리더보드 축하창 JavaScript 오류 수정

원인: 1~3등 축하창에서 사용하는 leaderboardSummaryText() 함수가 app.js에서 빠졌습니다.
서버 로그인과 리더보드 조회 이후 팝업 표시 시 오류가 발생하므로 Supabase 재설정이나 SQL 재실행이 필요하지 않습니다.

GitHub 적용 방법
1. PATCH ZIP을 압축 해제합니다.
2. app.js와 index.html을 GitHub 저장소 최상위(index.html이 있던 위치)에 덮어씁니다.
3. Commit changes / Push 후 배포를 확인합니다.
4. 사이트에서 Ctrl + Shift + R 로 새로고침합니다. (iPad에서는 페이지 다시 로드)

다른 파일은 변경하지 않아도 됩니다. 기존 학습 기록, 공용 리더보드 DB, 이미지, PDF, Tally는 그대로 유지됩니다.

테스트: JavaScript 파서 통과; 점수 표시 함수 단위 테스트 통과.
브라우저 통합 테스트와 실제 Supabase 연결 테스트는 이 환경에서 수행하지 못했습니다.
